# Towsif — Personal Portfolio

Responsive portfolio site (HTML, CSS, JS). Design: river-teal, jute-gold and a flag-red sun.

## Included
- Portrait photo
- About Me travel enthusiast introduction
- Education: Class 10, Government Bengali School
- Travel destinations from supplied travel document
- Email, Instagram and Facebook links

## Publish on GitHub Pages
Upload all files and the `assets` folder to your repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
